## Findings
**S1 HIGH: one POST crashes the server (confirmed live on a local server).** `server.js:119` JSON-parses the body, then
`src/lib/signup.js:33` reads `fields.website`. `curl -X POST -H 'Content-Type: application/json' -H 'Accept: application/json'
-d null <site>/api/signup` -> `TypeError: Cannot read properties of null (reading 'website')` in an async `'end'` callback ->
process exits; every later request is refused. No Origin header passes the check, so a bot loop keeps the site down.
Fix (Desktop): coerce to a plain object at server.js:119
(`const o = JSON.parse(raw || '{}'); fields = o && typeof o === 'object' && !Array.isArray(o) ? o : {}`), use `fields?.website`
in signup.js:33, and add an HTTP test posting `null`, `[]`, `"x"`, `5` (expect 400, server still answers). Defence in depth:
try/catch around `handle()` and the `'end'` callback (readFileSync at server.js:292/313 can also throw) and
`process.on('unhandledRejection', log)`. Ready-to-apply patch: `docs/review/patches/s1-signup-crash.md`.

**S2 MEDIUM (launch config): TRUST_PROXY.** Without `TRUST_PROXY=1` on Render, every visitor shares the proxy IP: sign-up
limit (5 / 10 min) becomes site-wide, five bad passwords lock "gabe" for everyone, and no HSTS. With Cloudflare's orange-cloud
proxy in front, the rightmost X-Forwarded-For is Cloudflare's edge: same effect. Keep DNS-only unless server.js reads
`CF-Connecting-IP`. Checklist rows added.

**S3 LOW:** sign-up same-origin check passes with no Origin and no Referer (`signup.js:21-22`); intended; per-IP limit +
honeypot cover it. Leave.

**S4 LOW:** a stolen session cookie stays valid up to 7 days (logout only clears the browser cookie; revocation = password-hash
change). Acceptable (HttpOnly, SameSite=Strict, Path=/edit, Secure in prod). Optional runbook step: rotate `SESSION_SECRET`.

**S5 LOW:** many IPs can lock "gabe" out for 60 min via the name-only lock (50 fails / h). Deliberate tradeoff; no change.

**S6 INFO:** CSP sound (`script-src 'self'`, `object-src 'none'`, `frame-ancestors 'self'`, `form-action 'self'`, Spotify +
YouTube frames only). `img-src https:` and `style-src 'unsafe-inline'` are broad but needed. Optional (Desktop):
`upgrade-insecure-requests`, `Cross-Origin-Opener-Policy: same-origin`.
