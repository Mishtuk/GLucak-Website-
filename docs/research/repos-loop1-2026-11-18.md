# Repo research, loop 1 (2026-11-18)

12 new repos found with `gh search repos` + awesome-list hops, all read via `gh api` tarballs (inert, grep / read only). Already-covered repos
(RESOURCES.md) were skipped. Safety evidence per repo: `repo-safety-log.md`. Verdicts: 4 USE-TEXT, 6 REFERENCE, 2 REJECT (no malware found).
Search note: the GitHub search API rate-limit (30 / min) ran out after about 25 queries, so security-area search was thin; picks there are
well-known projects.

## Website design

### miqdadbadjuber/anti-slop (MIT, 9.4k stars, 3 months, pushed 2026-11-17) USE-TEXT
- Applies to: design-review skill + designer / copywriter agents. 40 rules in 3 tiers, "slop patterns" catalog, a mandatory PASS / FAIL
  report, copywriting rules (copy tells: hype caps, emoji bullets, invented numbers), a11y-human skill (contrast, focus).
- Vendor (text only): `skills/antislop/SKILL.md` (strip "Already installed" lines 16-37 and "Two Usage Modes" which read
  `%APPDATA%\antislop\settings.json` and tell the agent to run `npx`), `skills/antislop-ui/SKILL.md`, `skills/antislop-copywriting/SKILL.md`,
  `skills/antislop-layoutmobile/SKILL.md`, `skills/antislop-human/SKILL.md` + `references/A11Y-PATTERNS.md`, `WCAG.md`. MIT, keep LICENSE.
  Note `antislop-human` / `antislop-ui` carry an extra `LICENSE-web-quality-skills`: vendor that file with them.
- Do not use: `.claude-plugin/` (launcher spawns python), `cli/` (installer), `contrast-*.py`, `rules/antislop.md` (wrapped in
  `<EXTREMELY_IMPORTANT>` always-on directive). Overlaps hallmark + design-review: take only what they lack (copy tells, layoutmobile).
- Weak points: its filter is "no direction"; our DESIGN.md supplies direction. 40 rules is long: pick, do not paste all.

### google-labs-code/design.md (Apache-2.0, 28.9k stars, org, pushed today) USE-TEXT
- Applies to: `DESIGN.md` structure and a future token file. Vendor `docs/spec.md` (624 lines, Apache-2.0 + NOTICE text) and the
  `examples/totality-festival/` folder as a worked dark-music example (colours include a bright yellow primary: check against our hard
  rule 1 / palette before copying anything). Do not run the CLI (`bun`, `npx @google/design.md lint`); its linter source uses
  `new Function` (spec-gen/compiler.ts:32) at build time, which is a reason not to run it, not a text risk.

### Moddingflow/better-design (MIT, 51 stars, 1 fork, 0 issues, 2 months) REFERENCE

  type, motion, images, copy), `motion.md`, `page-anatomy.md`, `art-direction.md`. Read and re-derive in our own words; vendor nothing.
  Its scripts spawn headless Chrome with `--remote-debugging-port` (not run).

### bergside/awesome-design-skills (MIT, 3.7k stars, org, pushed 2026-06) REFERENCE
