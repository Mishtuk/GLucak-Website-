# Repo safety log

One entry per outside GitHub repo we checked, per `docs/review/overhaul/overnight-plan.md` (credibility check + 7-step harm scan).
Method: `gh api repos/<o>/<r>/tarball/HEAD` extracted as inert data into a scratch folder, then grep / read only. Nothing cloned, installed
or run. Step 7 = separate read-only Sonnet reviewer. Verdicts: USE-TEXT (vendor .md text unchanged + licence + our overrides),
REFERENCE (read and cite, do not vendor), REJECT.

Step key: 1 file list (binaries, minified, eval/atob/escape runs) | 2 lifecycle scripts | 3 network / shell / secrets | 4 Claude hooks,
MCP, permission bypass, prompt injection, zero-width / bidi (grep `[U+200B-200F U+202A-202E U+2066-2069 U+FEFF]`) | 5 GitHub Actions |
6 history + issues (last 20 commits, last 100 issues grepped for malware / stolen / compromised / backdoor / exfiltrat / telemetry) | 7 second reviewer.
